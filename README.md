Entry for [One Word, One Username, One Reward](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae) on [make.fun](https://make.fun).

The entry is our own make.fun username, one word and nothing else:

```
quiet-kestrel-10
```

`main.ts` validates the handle (1–30 characters, a single word, no whitespace),
writes exactly that word to `/output/entry.txt` with no trailing newline, then
reads the file back and confirms it matches byte for byte. Two runs produce
identical bytes.
